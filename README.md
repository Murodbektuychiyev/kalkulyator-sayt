# Interaktiv Kalkulyator

Interaktiv, veb-brauzerda ishlaydigan oddiy kalkulyator. Ko‘rinishi va funksiyalari mashhur model kalkulyatoriga o‘xshash.  
HTML, CSS va JavaScript asosida yaratilgan.

---

[👉 Onlayn foydalanish uchun bu yerni bosing](https://kalkulyator-sayt.vercel.app/)  

---

## ⚡ Asosiy imkoniyatlari

- Raqamlar va arifmetik amallar: `+`, `−`, `×`, `÷`
- C (tozalash), %, `.` (nuqta), `+/-` (isporasini o‘zgartirish)
- Responsive dizayn (telefon va kompyuterda to‘g‘ri ko‘rinadi)
- Minimalist va real kalkulyatorga o‘xshash interfeys
